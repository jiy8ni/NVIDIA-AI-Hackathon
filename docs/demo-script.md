# 3분 데모

1. README대로 실행하고 운영 담당자로 온보딩 생성. 상단 offline/fixture 표시를 설명한다.
2. 홈은 5개 목차만 보여준다. '지금 할 일'에서 행사 정산 Task Contract를 연다.
3. 담당자·기한·완료 조건이 누락된 부분이 '확인 필요'인지 본다. 기록된 문서 소유자를 담당자로 채우지 않는다.
4. '열린 질문'에서 오래된 모임통장 안내와 최신 법인 계좌 **검토 중** 대화를 비교한다.
5. 대협은 논의 참여자라는 근거의 질문 후보이지 승인권자가 아님을 설명한다. 질문 초안은 전송되지 않는다.
6. 챗봇에 '법인인데 왜 모임통장?' 질문. Notion 조회 후 Slack 추가 검색, 양쪽 인용과 확인 질문을 보여준다.
7. setup 자료 하나를 완료 → 컨텍스트 새로고침 → 완료 상태가 유지되는지 본다.
8. 저장 문서 PDF를 내보내고 생성/조회 시점·원문 출처·미확정 표시를 확인한다.

offline 모델의 질문 판단은 제한된 결정적 기준선입니다. 실제 Nemotron 데모에서는 키/tokenizer 설정과 live 검증을 마친 후 모델 모드를 바꾸고 같은 질문을 다시 실행하세요. fixture 링크는 example.com이며 실제 사내 링크가 아닙니다.
